 PURPOSE
 -------
 This model quantifies and compares the environmental impact of two system
 configurations at an industrial facility in Germany:

   Configuration A : 1 MWp rooftop solar PV system (standalone)
   Configuration B : 1 MWp rooftop solar PV + 2 MWh NMC-BESS system

 The central question: Does adding a battery storage system improve or worsen
 the overall environmental profile when accounting for manufacturing emissions?

 METHODOLOGY
 -----------
 Follows ISO 14040:2006 (Principles & Framework) and ISO 14044:2006
 (Requirements & Guidelines) for Life Cycle Assessment.

 The model is structured along the four LCA phases:
   Phase 1 — Goal & Scope Definition
   Phase 2 — Life Cycle Inventory (LCI)
   Phase 3 — Life Cycle Impact Assessment (LCIA)
   Phase 4 — Interpretation (Carbon Payback + Sensitivity Analysis)

 SYSTEM BOUNDARY
 ---------------
 Cradle-to-gate: covers raw material extraction through manufacturing and
 installation. Excludes operational emissions (negligible for PV/BESS) and
 end-of-life (recycling/disposal) — documented as a study limitation.

 FUNCTIONAL UNIT
 ---------------
 1 MWh of electricity delivered to an industrial facility over the 25-year
 system lifetime. All impact scores are normalized to this unit.

 KEY SOURCES
 -----------
 [1] NREL LCA Harmonization Project — Life Cycle GHG Emissions from Solar PV
     https://docs.nrel.gov/docs/fy13osti/56487.pdf
 [2] Degen, F. & Schutte, M. (2021) — LCA of NMC battery production in Europe
     Journal of Cleaner Production
 [3] ScienceDirect (2024) — Numerical LCA of Li-NMC integrated with PV system
     GWP = 189 kg CO2-eq/kWh (openLCA + ecoinvent)
 [4] Fraunhofer ISE — Photovoltaics Report, solar yields for Germany
     https://www.ise.fraunhofer.de/en/publications/studies/photovoltaics-report.html
 [5] Umweltbundesamt (UBA) — German grid emission factor 2024: 363 g CO2/kWh
     https://www.umweltbundesamt.de
 [6] Wikipedia / BDEW — Electricity sector in Germany (2024): 363 g CO2/kWh
     https://en.wikipedia.org/wiki/Electricity_sector_in_Germany
 [7] EU REPowerEU / Klimaschutzprogramm — 2030 and 2035 grid targets
 [8] IRENA (2023) — Renewable Power Generation Costs
 [9] ecoinvent 3.9 database summaries — balance-of-system emission factors
================================================================================
"""

# ── Standard library & third-party imports ────────────────────────────────────
import numpy as np                      # numerical operations
import matplotlib.pyplot as plt         # plotting
import matplotlib.gridspec as gridspec  # multi-panel chart layout


# ╔══════════════════════════════════════════════════════════════════════════════
# ║  PHASE 1 — GOAL & SCOPE DEFINITION
# ║
# ║  Purpose : Define what is being studied, why, and where the boundaries are.
# ║  ISO ref : ISO 14040 §4.2, ISO 14044 §4.2
# ╚══════════════════════════════════════════════════════════════════════════════

# ── Study identification ───────────────────────────────────────────────────────
STUDY_TITLE      = "LCA & Carbon Payback — Industrial PV + NMC-BESS (Germany)"
SYSTEM_BOUNDARY  = "Cradle-to-gate (manufacturing + installation; excl. EOL)"
FUNCTIONAL_UNIT  = "1 MWh of electricity delivered over a 25-year system lifetime"
INTENDED_USE     = "Portfolio project; internal decision-support level (no public comparative assertion)"

# ── PV system parameters ──────────────────────────────────────────────────────
#
# Technology : Monocrystalline silicon (mono-Si), most common for industrial
#              rooftop installations in Germany due to high efficiency (~21%)
#              and well-documented LCA data.
#
PV_CAPACITY_MWP  = 1.0      # Installed peak capacity [MWp]
                             # Represents a medium-sized industrial rooftop system.

PV_LIFETIME_YR   = 25       # System operational lifetime [years]
                             # Industry standard for warranty and LCA studies.
                             # Source: IEC 61215, most manufacturer warranties.

PV_YIELD_KWH_KWP = 950      # Specific annual yield [kWh/kWp/year]
                             # Representative value for central Germany (e.g. Halle,
                             # Leipzig region). Range: 900–1050 kWh/kWp/yr.
                             # Source: Fraunhofer ISE Photovoltaics Report [4]

PV_DEGRADATION   = 0.005    # Annual power degradation rate [fraction/year]
                             # i.e. panels lose 0.5% output per year due to aging.
                             # After 25 years: ~88% of initial output remaining.
                             # Source: NREL, Jordan & Kurtz (2013), typical mono-Si.

# ── NMC-BESS (Battery Energy Storage System) parameters ──────────────────────
#
# Chemistry : NMC = Lithium Nickel Manganese Cobalt Oxide (LiNiMnCoO2)
#             Most widely deployed chemistry for stationary industrial BESS.
#             Higher energy density than LFP but more emission-intensive to
#             manufacture due to cobalt and nickel content.
#
BESS_CAPACITY_MWH = 2.0     # Installed storage capacity [MWh]
                             # 2:1 ratio (MWh:MWp) is standard sizing for
                             # industrial self-consumption optimization.

BESS_LIFETIME_YR  = 12      # NMC battery operational lifetime [years]
                             # Based on ~3,000–4,000 charge cycles at 1 cycle/day.
                             # Translates to ~8–11 years (conservative: 12 yrs).
                             # Source: ecoinvent 3.9, Degen & Schutte 2021 [2]
                             # ASSUMPTION: battery replaced at end of lifetime.
                             # Over 25-year PV lifetime → 3 battery installations
                             # (year 0, year 12, year 24).

BESS_EFFICIENCY   = 0.93    # Round-trip efficiency [-]
                             # Fraction of electricity recovered after storage.
                             # i.e. 7% lost as heat in each charge-discharge cycle.
                             # Source: IRENA (2023), typical NMC stationary BESS [8]

BESS_DOD          = 0.90    # Depth of discharge [-]
                             # Only 90% of nameplate capacity used per cycle to
                             # protect battery lifespan. Standard operating practice.

BESS_STORAGE_FRAC = 0.40    # Fraction of annual PV generation routed through BESS
                             # ASSUMPTION: 40% of solar output is stored and later
                             # discharged. Remaining 60% is consumed directly.
                             # This is a simplifying assumption for a system without
                             # a detailed dispatch model. Sensitivity analysis below
                             # covers the impact of varying this parameter.

# ── Grid carbon intensity scenarios ───────────────────────────────────────────
#
# These values drive the carbon payback calculation.
# They represent the CO2 emitted per kWh drawn from the German national grid.
# As the grid decarbonizes, each kWh of solar displaced saves less CO2,
# which paradoxically extends the carbon payback period.
#
# Unit: kg CO2-eq per kWh of grid electricity consumed
#
GRID_SCENARIOS = {

    "2024 (latest data)":  0.363,
    # Source: Official 2024 data. In 2024, an average of 363 g CO2/kWh was
    # emitted per kWh of electricity consumed in Germany (down from 433 g in 2022).
    # Source: BDEW / Wikipedia Electricity sector in Germany [6],
    #         Umweltbundesamt (UBA) [5]

    "2030 (target)":  0.200,
    # Source: EU REPowerEU plan and German Klimaschutzprogramm 2030.
    # Germany targets 80% renewable electricity by 2030.
    # This 200 g/kWh estimate is consistent with multiple scenario analyses
    # (Agora Energiewende, Fraunhofer ISE).
    # NOTE: This is a policy target, not a measured value. Actual outcome
    # will depend on deployment rates and grid flexibility.

    "2035 (projection)": 0.100,
    # Source: Fraunhofer ISE long-term scenarios; consistent with near-100%
    # renewable electricity grids in Western Europe by mid-2030s.
    # NOTE: This is a projection under ambitious decarbonization. Labeled
    # explicitly as a projection to avoid misleading readers.
}


# ╔══════════════════════════════════════════════════════════════════════════════
# ║  PHASE 2 — LIFE CYCLE INVENTORY (LCI)
# ║
# ║  Purpose : Quantify all material and energy inputs, and all environmental
# ║            emissions associated with the system, per unit of component.
# ║
# ║  ISO ref : ISO 14044 §4.3
# ║
# ║  All emission factors below are per unit of manufactured component.
# ║  They represent cradle-to-gate manufacturing impacts only.
# ║  Operational impacts are excluded (negligible for solar PV systems).
# ╚══════════════════════════════════════════════════════════════════════════════

# ── Impact categories being assessed ─────────────────────────────────────────
#
# Three impact categories selected as most relevant for energy systems:
#
#   GWP    — Global Warming Potential [kg CO2-equivalent]
#             Characterization method: IPCC AR6, GWP100
#             Most critical for climate-related decision making.
#
#   PED    — Primary Energy Demand [MJ]
#             Total energy (fossil + renewable) consumed in manufacturing.
#             Relevant for energy security and resource efficiency analysis.
#
#   WU     — Water Use [m3]
#             Freshwater consumption in manufacturing.
#             Relevant for water-stressed regions and supply chain risk.
#
CATEGORIES = [
    "GWP [kg CO2-eq]",
    "Primary Energy [MJ]",
    "Water Use [m3]",
]

# ── PV module manufacturing inventory ─────────────────────────────────────────
#
# Technology: Monocrystalline silicon (mono-Si) PV modules
# Scope: Cell manufacturing, module assembly, glass, aluminum frame, EVA encapsulant
# Unit: per kWp of installed capacity
#
# ASSUMPTIONS & SOURCES:
#   GWP: 400 kg CO2-eq/kWp
#     Source: NREL LCA Harmonization Project [1] — harmonized mean for mono-Si PV.
#     The NREL project reviewed >2,100 LCA studies and harmonized to consistent
#     assumptions (1,700 kWh/m2/yr irradiation, 30-yr lifetime).
#     Back-converted to per-kWp using: 950 kWh/kWp/yr × 25 yr = 23,750 kWh/kWp
#     Literature range: 350–600 kg CO2-eq/kWp depending on manufacturing location.
#     Conservative (mid-range) value used here.
#
#   Primary Energy: 6,500 MJ/kWp
#     Source: Consistent with NREL harmonization data and ecoinvent 3.9 [9]
#     Represents energy intensity of silicon purification + cell processing.
#     Literature range: 5,000–9,000 MJ/kWp
#
#   Water Use: 15 m3/kWp
#     Source: ecoinvent 3.9 database summaries [9]
#     Dominated by ultra-pure water use in silicon wafer and cell manufacturing.
#     Literature range: 10–25 m3/kWp
#
PV_INVENTORY = {
    "GWP [kg CO2-eq]"   : 400,     # kg CO2-eq per kWp  [1]
    "Primary Energy [MJ]": 6_500,   # MJ per kWp          [1][9]
    "Water Use [m3]"     : 15,      # m3 per kWp          [9]
}

# ── NMC battery manufacturing inventory ───────────────────────────────────────
#
# Technology: NMC (Lithium Nickel Manganese Cobalt Oxide) lithium-ion battery
# Scope: Cell manufacturing (cathode, anode, electrolyte, separator),
#        module assembly, battery management system (BMS), housing/casing
# Unit: per kWh of nameplate storage capacity
#
# ASSUMPTIONS & SOURCES:
#   GWP: 180 kg CO2-eq/kWh
#     This represents a global average for NMC battery manufacturing,
#     primarily reflecting Chinese production (dominant market share today).
#     Published range across studies:
#       - 189 kg CO2-eq/kWh: ScienceDirect 2024 (openLCA + ecoinvent) [3]
#       - 89–169 kg CO2-eq/kWh: range across manufacturing locations [3]
#       - 73–125 kg CO2-eq/kWh: European Gigafactory scenarios [3]
#       - 64.5 kg CO2-eq/kWh: US manufacturing (NREL/DOE 2023)
#     Value of 180 chosen as conservative central estimate for
#     batteries sourced globally (not specifically European production).
#     SENSITIVITY: European-manufactured NMC could be 100–130 kg CO2-eq/kWh.
#
#   Primary Energy: 2,500 MJ/kWh
#     Source: ecoinvent 3.9 summaries [9]; consistent with Degen & Schutte [2]
#     Dominated by cell manufacturing energy (30–50 kWh per kWh cell capacity)
#     and cathode active material production.
#
#   Water Use: 4 m3/kWh
#     Source: ecoinvent 3.9 [9]
#     Dominated by cathode material processing and cell formation steps.
#
BESS_INVENTORY = {
    "GWP [kg CO2-eq]"   : 180,     # kg CO2-eq per kWh capacity  [2][3]
    "Primary Energy [MJ]": 2_500,   # MJ per kWh capacity         [2][9]
    "Water Use [m3]"     : 4,       # m3 per kWh capacity         [9]
}

# ── Balance of System (BOS) inventory ─────────────────────────────────────────
#
# Includes: inverter(s), DC/AC cabling, mounting structure (aluminum/steel),
#           combiner boxes, monitoring system, installation labor energy
# Unit: per kWp of installed PV capacity
#
# ASSUMPTIONS & SOURCES:
#   GWP: 80 kg CO2-eq/kWp
#     Source: ecoinvent 3.9 [9]; consistent with Fthenakis & Kim (2011)
#     Dominated by inverter manufacturing and aluminum mounting structure.
#     Literature range: 60–120 kg CO2-eq/kWp
#
#   Primary Energy: 1,200 MJ/kWp
#     Source: ecoinvent 3.9 [9]
#
#   Water Use: 2 m3/kWp
#     Source: ecoinvent 3.9 [9]
#
BOS_INVENTORY = {
    "GWP [kg CO2-eq]"   : 80,      # kg CO2-eq per kWp  [9]
    "Primary Energy [MJ]": 1_200,   # MJ per kWp         [9]
    "Water Use [m3]"     : 2,       # m3 per kWp         [9]
}


def compute_lci(include_bess: bool) -> dict:
    """
    Phase 2 — Compute the Life Cycle Inventory.

    Aggregates all manufacturing impacts for the full system.
    Returns absolute total impacts for each impact category.

    Parameters
    ----------
    include_bess : bool
        True  → PV + NMC-BESS system (Configuration B)
        False → PV only system (Configuration A)

    Returns
    -------
    dict : {category: total_impact_value}
           Values are absolute totals (not yet normalized to functional unit).

    Notes
    -----
    Battery replacements:
        NMC lifetime = 12 years. PV lifetime = 25 years.
        ceil(25 / 12) = 3 battery installations over system lifetime.
        (Year 0: initial installation, Year 12: 1st replacement,
         Year 24: 2nd replacement — this last one has only 1 year of use,
         which is a conservative assumption that slightly overstates impact.)
    """

    # Convert MWp to kWp (emission factors are defined per kWp)
    pv_kwp = PV_CAPACITY_MWP * 1_000   # 1.0 MWp × 1000 = 1000 kWp

    lci = {}

    for cat in CATEGORIES:

        # PV modules — scale emission factor by system size
        pv_total  = PV_INVENTORY[cat]  * pv_kwp
        # Example (GWP): 400 kg CO2/kWp × 1000 kWp = 400,000 kg CO2

        # Balance of system — same scaling
        bos_total = BOS_INVENTORY[cat] * pv_kwp
        # Example (GWP):  80 kg CO2/kWp × 1000 kWp =  80,000 kg CO2

        if include_bess:
            # Number of battery installations over 25-year lifetime
            # ceil(25/12) = ceil(2.08) = 3
            replacements = int(np.ceil(PV_LIFETIME_YR / BESS_LIFETIME_YR))

            # Battery capacity in kWh (2 MWh = 2000 kWh)
            bess_kwh = BESS_CAPACITY_MWH * 1_000

            # Total battery impact = impact per kWh × capacity × number of installations
            bess_total = BESS_INVENTORY[cat] * bess_kwh * replacements
            # Example (GWP): 180 × 2000 × 3 = 1,080,000 kg CO2
        else:
            bess_total = 0.0

        # Sum all components
        lci[cat] = pv_total + bos_total + bess_total

    return lci


# ╔══════════════════════════════════════════════════════════════════════════════
# ║  PHASE 3 — LIFE CYCLE IMPACT ASSESSMENT (LCIA)
# ║
# ║  Purpose : Convert absolute LCI results into impact scores per functional
# ║            unit. This is called "characterization" in ISO 14044.
# ║
# ║  ISO ref : ISO 14044 §4.4
# ║
# ║  Characterization step:
# ║    impact score = total_LCI_impact / total_MWh_delivered
# ║
# ║  The denominator (MWh delivered) is calculated accounting for:
# ║    - Panel degradation over 25 years (0.5%/year)
# ║    - Round-trip efficiency losses when electricity passes through BESS
# ╚══════════════════════════════════════════════════════════════════════════════

def compute_electricity_delivered(include_bess: bool) -> float:
    """
    Calculate total electricity delivered to the facility over 25-year lifetime.

    This is the denominator of the functional unit normalization.

    The calculation accounts for:
      1. Annual PV yield (950 kWh/kWp/yr for central Germany)
      2. Panel degradation: output reduces by 0.5% each year
      3. BESS round-trip losses: 7% of electricity lost when stored + discharged

    Parameters
    ----------
    include_bess : bool
        True  → 40% of generation passes through battery (losing 7%)
        False → all generation delivered directly (no losses)

    Returns
    -------
    float : Total MWh delivered over 25-year lifetime

    Example calculation (Year 1, PV only):
        1000 kWp × 950 kWh/kWp × (1 - 0.005)^1 = 945,250 kWh = 945.25 MWh
    """

    total_mwh = 0.0

    for year in range(1, PV_LIFETIME_YR + 1):

        # Annual generation accounting for cumulative degradation
        # Formula: capacity × yield × (1 - degradation_rate)^year
        annual_pv_kwh = (
            PV_CAPACITY_MWP * 1_000   # kWp
            * PV_YIELD_KWH_KWP        # kWh/kWp/yr
            * (1 - PV_DEGRADATION) ** year
        )

        if include_bess:
            # Split generation into direct use and battery-routed use
            # Direct (60%): consumed immediately, no losses
            direct_kwh  = annual_pv_kwh * (1 - BESS_STORAGE_FRAC)

            # Via BESS (40%): passes through battery, loses 7%
            via_bess_kwh = annual_pv_kwh * BESS_STORAGE_FRAC * BESS_EFFICIENCY

            total_mwh += (direct_kwh + via_bess_kwh) / 1_000  # kWh → MWh

        else:
            # PV only: all generation delivered directly
            total_mwh += annual_pv_kwh / 1_000  # kWh → MWh

    return total_mwh


def compute_lcia(lci: dict, mwh_delivered: float) -> dict:
    """
    Phase 3 — Characterize LCI results per functional unit.

    Divides absolute manufacturing impacts by total electricity delivered.
    This gives the environmental cost per MWh of electricity provided —
    the standardized impact score that enables fair comparison.

    Parameters
    ----------
    lci          : dict  — absolute manufacturing impacts from compute_lci()
    mwh_delivered: float — total MWh delivered from compute_electricity_delivered()

    Returns
    -------
    dict : {category: impact_per_MWh_delivered}

    Example (GWP, PV only):
        480,000 kg CO2 total ÷ 22,266 MWh delivered = 21.6 kg CO2/MWh
    """
    return {
        cat: lci[cat] / mwh_delivered
        for cat in CATEGORIES
    }


# ╔══════════════════════════════════════════════════════════════════════════════
# ║  PHASE 4 — INTERPRETATION
# ║
# ║  Purpose : Identify significant issues, check sensitivity, and draw
# ║            conclusions consistent with the goal and scope.
# ║
# ║  ISO ref : ISO 14044 §4.5
# ║
# ║  Two analyses:
# ║    (A) Carbon payback period — for each grid scenario
# ║    (B) Sensitivity analysis — payback vs. grid intensity range
# ╚══════════════════════════════════════════════════════════════════════════════

def compute_carbon_payback(lci: dict, grid_intensity: float) -> float:
    """
    Phase 4A — Calculate carbon payback period.

    The carbon payback period is the number of years until the cumulative
    CO2 avoided by displacing grid electricity equals the CO2 emitted
    during system manufacturing.

    Logic:
      - Every year the system operates, it delivers solar electricity.
      - Each MWh delivered displaces one MWh that would otherwise come from
        the grid, avoiding (grid_intensity × MWh) kg of CO2.
      - We accumulate avoided CO2 year by year.
      - The year when cumulative avoided CO2 >= manufacturing CO2 is the payback.

    Key insight: As the grid decarbonizes (lower grid_intensity), each MWh
    displaced saves less CO2. This means payback periods get LONGER as the
    grid gets cleaner — a counterintuitive but important consulting insight.

    Parameters
    ----------
    lci           : dict  — absolute LCI results (contains manufacturing GWP)
    grid_intensity: float — kg CO2-eq per kWh of grid electricity [kg CO2/kWh]

    Returns
    -------
    float : Payback period in years.
            Returns float('inf') if payback not achieved within 25-year lifetime.

    Units note:
        manufacturing_gwp is in kg CO2.
        annual_pv_kwh × grid_intensity gives kg CO2 avoided.
        Both divided by 1000 to work in tonnes (avoids floating point issues).
    """

    manufacturing_gwp_tonnes = lci["GWP [kg CO2-eq]"] / 1_000  # kg → tonnes CO2

    cumulative_avoided_tonnes = 0.0

    for year in range(1, PV_LIFETIME_YR + 1):

        # Annual generation with degradation (same formula as electricity delivered)
        annual_pv_kwh = (
            PV_CAPACITY_MWP * 1_000
            * PV_YIELD_KWH_KWP
            * (1 - PV_DEGRADATION) ** year
        )

        # CO2 avoided this year = electricity generated × grid emission factor
        # (assumes 1:1 displacement of grid electricity — valid for industrial
        #  self-consumption where solar directly offsets grid imports)
        avoided_this_year = (annual_pv_kwh * grid_intensity) / 1_000  # → tonnes

        cumulative_avoided_tonnes += avoided_this_year

        # Check if manufacturing debt is paid off
        if cumulative_avoided_tonnes >= manufacturing_gwp_tonnes:
            return float(year)

    # Payback not reached within system lifetime — very long payback on clean grids
    return float("inf")


def compute_sensitivity(include_bess: bool, base_grid: float) -> dict:
    """
    Phase 4B — Sensitivity analysis on grid carbon intensity.

    Tests how the carbon payback period changes if the grid intensity
    varies between 50% and 150% of the base case value.

    This is required by ISO 14044 §4.5.3 for parameters with significant
    uncertainty. Grid carbon intensity is the most influential parameter
    in this model.

    Parameters
    ----------
    include_bess : bool  — which configuration to analyze
    base_grid    : float — base case grid intensity [kg CO2/kWh]

    Returns
    -------
    dict with keys:
        'grid_values' : array of tested grid intensities
        'paybacks'    : array of corresponding payback years
    """

    lci = compute_lci(include_bess)

    # Test 30 evenly spaced values from 50% to 150% of base grid intensity
    grid_values = np.linspace(base_grid * 0.50, base_grid * 1.50, 30)

    paybacks = [compute_carbon_payback(lci, g) for g in grid_values]

    return {
        "grid_values": grid_values,
        "paybacks"   : paybacks,
    }

def print_results_table(
    lci_pv, lci_bess,
    mwh_pv, mwh_bess,
    lcia_pv, lcia_bess,
    paybacks
):
    """Print a formatted summary of all LCA results to the console."""

    SEP = "=" * 68

    print(f"\n{SEP}")
    print(f"  {STUDY_TITLE}")
    print(f"  Functional unit : {FUNCTIONAL_UNIT}")
    print(f"  System boundary : {SYSTEM_BOUNDARY}")
    print(SEP)

    # ── Phase 2 results: absolute LCI totals ──────────────────────────────────
    print("\n  PHASE 2 — Life Cycle Inventory (absolute totals)")
    print(f"  {'':32s} {'PV only':>14} {'PV + BESS':>14}")
    print("  " + "-" * 62)
    for cat in CATEGORIES:
        print(f"  {cat:<32} {lci_pv[cat]:>14,.0f} {lci_bess[cat]:>14,.0f}")

    # ── Phase 3 results: LCIA per functional unit ─────────────────────────────
    print(f"\n  PHASE 3 — LCIA per Functional Unit (per MWh delivered)")
    print(f"  {'':32s} {'PV only':>14} {'PV + BESS':>14}")
    print("  " + "-" * 62)
    print(f"  {'MWh delivered (25 yr)':<32} {mwh_pv:>14,.1f} {mwh_bess:>14,.1f}")
    for cat in CATEGORIES:
        print(f"  {cat:<32} {lcia_pv[cat]:>14.3f} {lcia_bess[cat]:>14.3f}")

    # ── Phase 4 results: carbon payback ───────────────────────────────────────
    print(f"\n  PHASE 4 — Carbon Payback Period [years]")
    print(f"  {'Grid Scenario':<28} {'PV only':>12} {'PV + BESS':>12}")
    print("  " + "-" * 54)
    for label, pb in paybacks.items():
        pv_val   = f"{pb['PV only']:.1f}" if pb['PV only'] != float("inf") else ">25"
        bess_val = f"{pb['PV + BESS']:.1f}" if pb['PV + BESS'] != float("inf") else ">25"
        print(f"  {label:<28} {pv_val:>12} {bess_val:>12}")

    print(f"\n  NOTE: Payback >25 yr means system lifetime expires before break-even.")
    print(f"  This is expected for clean grids — the solar system still reduces")
    print(f"  lifetime emissions, but does not fully offset manufacturing impact.\n")


def plot_results(lcia_pv, lcia_bess, paybacks, base_grid=0.363):
    """
    Generate all five result charts and save to output file.

    Charts produced:
      1. GWP per functional unit (bar chart)
      2. Primary energy per functional unit (bar chart)
      3. Water use per functional unit (bar chart)
      4. Carbon payback by grid scenario (grouped bar chart)
      5. Sensitivity: payback vs. grid intensity (line chart)
    """

    fig = plt.figure(figsize=(17, 11))
    fig.suptitle(
        "LCA & Carbon Payback — Industrial PV + NMC-BESS System (Germany)\n"

        """Apply consistent styling to an axes object."""
        ax.set_title(title, fontsize=10, fontweight="bold", pad=8)
        ax.set_ylabel(ylabel, fontsize=9)
        ax.spines[["top", "right"]].set_visible(False)
        ax.tick_params(labelsize=9)

    # ── Chart 1: GWP per functional unit ──────────────────────────────────────
    ax1 = fig.add_subplot(gs[0, 0])
    gwp_vals = [lcia_pv["GWP [kg CO2-eq]"], lcia_bess["GWP [kg CO2-eq]"]]

        0.5, -0.18,

    ax4 = fig.add_subplot(gs[1, 0:2])

    # System lifetime reference line
    ax4.axhline(
        PV_LIFETIME_YR, color="#888", linestyle="--",

    ax4.set_xticks(x)

    ax4.legend(frameon=False, fontsize=9)
    style_ax(
        ax4,
        "Carbon Payback Period by Grid Scenario",
        "Years to carbon break-even"

    ax4.text(
        0.5, -0.15,
        "As the grid decarbonizes, each kWh displaced saves less CO₂ → payback takes longer",

    # ── Chart 5: Sensitivity — payback vs grid intensity ──────────────────────

    fig.text(
        0.01, 0.005,
        "Sources: NREL LCA Harmonization Project [1]; ecoinvent 3.9 [9]; "
        "Degen & Schutte 2021 [2]; UBA / BDEW 2024 [5][6]; "

        fontsize=7, color="#888"

# ║  MAIN — Run full LCA
# ╚══════════════════════════════════════════════════════════════════════════════

def run_lca():
    """
    Main function — runs the complete four-phase LCA and produces all outputs.

    Execution order:
      1. Phase 2: compute LCI for both configurations
      2. Phase 3: normalize to functional unit (LCIA)
      3. Phase 4: carbon payback for all grid scenarios
      4. Print results table
      5. Generate and save charts
    """

    print("\n  Running LCA model...")

    # ── Phase 2: Life Cycle Inventory ─────────────────────────────────────────
    lci_pv_only = compute_lci(include_bess=False)
    lci_pv_bess = compute_lci(include_bess=True)

    # ── Phase 3: Electricity delivered + LCIA normalization ───────────────────
    mwh_pv_only = compute_electricity_delivered(include_bess=False)
    mwh_pv_bess = compute_electricity_delivered(include_bess=True)

    lcia_pv_only = compute_lcia(lci_pv_only, mwh_pv_only)
    lcia_pv_bess = compute_lcia(lci_pv_bess, mwh_pv_bess)

    # ── Phase 4: Carbon payback for all scenarios ──────────────────────────────
    paybacks = {}
    for label, intensity in GRID_SCENARIOS.items():
        paybacks[label] = {
            "PV only"  : compute_carbon_payback(lci_pv_only, intensity),
            "PV + BESS": compute_carbon_payback(lci_pv_bess, intensity),
        }

    # ── Print results ──────────────────────────────────────────────────────────
    print_results_table(
        lci_pv_only, lci_pv_bess,
        mwh_pv_only, mwh_pv_bess,
        lcia_pv_only, lcia_pv_bess,
        paybacks
    )

    # ── Generate charts ────────────────────────────────────────────────────────
    plot_results(
        lcia_pv_only, lcia_pv_bess,
        paybacks,
        base_grid=0.363   # 2024 German grid: 363 g CO2/kWh [5][6]
    )


# ── Entry point ───────────────────────────────────────────────────────────────
if __name__ == "__main__":
    run_lca()
